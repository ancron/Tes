# Burning Rose: план эдита (по скиллу phonk-visualizer)

**Концепт.** Роза тлеет во тьме → вспыхивает → взрывается лепестками, из её сердцевины рождается кольцо света → лепестки кружат вихрем → пролёт сквозь кольцо → в огненном мире лепестки собираются обратно, роза горит → угасает до тления → петля.

**Эмоциональная дуга:** тёмная меланхолия → напряжение → катарсис (дроп) → транс (вихрь) → благоговение (пролёт) → возрождение → покой и петля.

**Матч-кат по форме:** сердцевина розы = кольцо света.

## Трек (свой, `make_track.py`)
- 152 BPM, half-time, соль минор, 8 тактов = 12.632 с = 379 кадров при 30 fps.
- 1 такт = 47.37 кадра, 1 доля = 11.84 кадра.
- Бас по тактам: G1, G1 | E♭1→F1 | **дроп**: G1 | G1→B♭1 | E♭1 | D1→F1 | G1 (аутро совпадает с интро).
- Брейк: последняя доля 3-го такта (кадры 130–141). Дроп: 4-й такт, кадр 142.
