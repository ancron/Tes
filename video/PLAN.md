# «Rose / Ash»: план кадров (скилл phonk-visualizer)

**Концепт.** Роза рождается из дыма. К ней тянутся руки, в луче стоит фигура. Роза вспыхивает, наступает тишина, затем взрыв: капли и огонь. Дальше красные чернила, танец в дыму, руки «поют» вокальную линию, удар-инверсия. Роза сгорает в дым, и петля замыкается.

**Эмоции:** тайна → тревога → «вдох» → катарсис → транс → тлен.

**Своя макроструктура:** без кольца с обломками и без пролёта сквозь кольцо.

**Звук:** трек из референса пользователя, 12.05 с = 362 кадра при 30 fps.
- **Кики:** 9, 32, 56, 79, 102, 149, 173, 196, 220, 243, 266, 290, 313, 337, 360.
- **Брейк:** 134–148. **Дроп:** 149.
- **Вокальные линии:** 30–72 (тональная около 1 кГц) и 270–345 (скользящая).

**Материал:** только Mixkit Free License (`ASSETS.md`). Грейд офлайн: `scripts/grade.py` переводит яркость в палитру — истинный чёрный → вино → кримсон → белое ядро; для сцены «холодных рук» используется холодная палитра.
