# Антипример: «Burning Rose» (оценка пользователя: «жесть»)

Файлы: `edits/burning-rose/` (ролик, план, код). Ролик используется как **калибровочный образец плохого** для критиков: если критик ставит ему больше 4/10, он сломан.

## Что было сделано

- Вся картинка нарисована формулами в numpy/OpenCV (самописная библиотека `lib/fxkit.py`), без видеоредактора и без живого материала.
- Трек синтезирован (`lib/phonk_synth.py`).
- Перед показом «пройдены все проверки», но проверки мерили не то.
